# Changelog

## 0.1.0

First release.

- Request editor with params, headers, body (JSON, text, XML, form, multipart, binary) and auth (Bearer, Basic, API key, inherit).
- Response viewer with pretty JSON/XML/HTML, image preview, headers, copy and save.
- Collections with folders, stored as JSON in `.restly/` or in global storage.
- Environments with `{{variables}}`, dynamic variables and secret values in SecretStorage.
- Response tests and "set env var" for chained requests.
- History of sent requests.
- Import from cURL, Postman collections v2.x and Postman environments; export collections.
- Code snippets for cURL, fetch, axios and Python requests.
